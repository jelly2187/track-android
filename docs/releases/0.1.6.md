# Track 0.1.6

恢复 App 内下载与系统安装确认，更新无需跳转浏览器。

- 点击“下载更新”后直接下载 APK，支持取消或选择“后台下载”继续使用应用。
- 收起后，后续进度和下载完成都不会重新弹窗；可在设置中查看进度和已下载更新。
- 下载校验大小、SHA-256、包名、版本与签名；安装前再次检查。首次需允许 Track 安装应用，最终由系统确认安装。
- 已完整下载且校验通过的缓存可复用；损坏或签名不匹配的文件不会进入安装流程。
- 保留关闭同版本提示的记忆、小组件同步修复和减少后台唤醒的改进。

0.1.4 / 0.1.5 用户需通过现有浏览器入口或本仓库发布页覆盖安装一次，之后恢复 App 内更新。保持原签名、包名和本地数据，无需卸载。

本版本重新声明用户确认安装所需的 REQUEST_INSTALL_PACKAGES 权限，用于 Track 自身更新；不在后台自动安装。安装风险提示的厂商复核状态未改变，具体检查说明见 `docs/INSTALLATION_SAFETY.md`。
