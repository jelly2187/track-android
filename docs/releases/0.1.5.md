# Track 0.1.5

修复更新提示收起后反复弹出、打断正常使用的问题。

- 更新弹窗与检查状态分开管理，新的检查结果不再直接强制打开弹窗。
- 点击“稍后”、关闭弹窗或成功前往浏览器下载后，同一发布版本不再自动弹出；这个选择会保存到本机，重新打开应用也有效。
- 设置中的“检查更新”仍可主动查看该版本，新发布的版本仍会正常提示。
- 延续浏览器下载更新和较少权限方案，不恢复应用内 APK 下载、后台下载或安装应用权限。

如果仍在使用带“后台下载”按钮的旧版，请直接用浏览器从本仓库下载新版覆盖安装，避免旧版下载进度触发重复弹窗。

安装风险提示仍在调查：用户已反馈 0.1.4 继续被标记，具体风险名称及检测引擎尚未取得，本版本不宣称已经通过厂商安全复核。复核资料与处理说明见 `docs/INSTALLATION_SAFETY.md`。

保持原签名和包名，覆盖安装可保留习惯、记录和小组件配置。
