# Track 0.1.7

这次更新把连续打卡进度带进通知，并为每个习惯加入六枚里程碑徽章。

- 提醒会显示首次打卡、当前连续次数或重新开始的提示。计量习惯会同时显示今天的完成量，例如「喝水 · 3/6 杯 · 已连续完成 6 次」。
- 今天达标即可解锁新徽章时，展开通知可以看到提示。多项提醒仍会合并，并沿用已设置的提醒时间、重复间隔和静音时段。
- 在习惯详情可以查看「首次完成」和连续 3、7、14、30、100 次徽章，以及离下一枚徽章的进度。徽章会按已有打卡记录计算，补记或更正后自动更新。
- 在 App 内解锁徽章会短暂显示祝贺。通过通知或桌面小组件打卡获得的徽章也会出现在习惯详情中。

0.1.6 用户可在 Track 的设置中检查更新。也可以用同签名 APK 覆盖安装，保留已有打卡记录。
