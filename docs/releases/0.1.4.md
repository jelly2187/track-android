# Track 0.1.4

减少安装权限和不必要的后台唤醒，补充隐私与安装检查说明。

- 保留启动检查更新，下载改为点击后前往浏览器；Track 不再申请安装其他应用的权限，也不再提供本地 APK 下载和安装入口。
- 移除未使用的前台服务权限，关闭明文网络，收紧系统事件接收器。
- 取消旧的每 30 分钟全局轮询。没有有效提醒或通知权限关闭时取消提醒唤醒，每周计划直接等待下一个实际提醒时间。
- 夜间暂停重复唤醒，保留用户明确设定时间的静默通知；新增“不重复”选项，原有 15/30/60 分钟设置仍可用。
- 设置中增加隐私与权限说明，公开安装风险检查与厂商复核方法。
- 保留 0.1.3 的小组件状态同步修复。

本版本改进权限与调度设计，不代表已经通过手机厂商的安全复核。若仍显示风险提示，需要结合具体引擎、风险名称与文件指纹进一步定位，检查说明见项目的 `docs/INSTALLATION_SAFETY.md`。

保持同一签名、包名和本地数据，直接覆盖安装，无需卸载旧版。
