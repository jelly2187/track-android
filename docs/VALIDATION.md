# v0.1.0 验证记录

## 已验证

- 发布 APK 构建和本地专用签名；应用最低 API 26、目标 API 37。
- 7 项 JVM 规则测试：每周计划、跨午夜静音、数值累计、休息日连续记录、当天待确认、历史目标、多时间提醒去重与跨日调度。
- 4 项 Robolectric / API 34 数据库测试：事务与事件去重、过期外部操作、保留进度的未完成确认、JSON 备份恢复与版本校验、目标修改不改变过去。
- 1 项 Robolectric / API 34 通知测试：创建通知渠道与常驻通知、操作按钮、闹钟注册、完成后取消通知。
- 2 项 Robolectric / API 34 界面测试：浅色、深色习惯卡片渲染及计数按钮交互。PNG 位于 `artifacts/previews`；这是组件测试截图，并非 OPPO 真机截图。
- Android Lint 无错误；保留固定依赖版本、旧系统忽略新属性及编码风格建议等警告。
- Android 设备测试源码与测试 APK 可编译，包含真实设备上的计数操作、通知同步和数据库测试。

最终命令和 HTML/XML 报告存放在 `artifacts/reports`。开发中发现的编译、KSP 配置、Windows 路径转义及 Robolectric 截图问题已修复后重跑。

## 尚待真机验证

当前未连接 OPPO Find X9 Pro。Windows 模拟器硬件加速不可用，软件模式模拟器未完成引导，已停止；因此不将模拟器或真机测试标记为通过。Robolectric 不能替代真实系统后台调度、桌面宿主或厂商省电行为。

在 ColorOS 16 上逐项验证，升级 ColorOS 17 后重复：

1. 新装后通知授权、精确提醒授权及拒绝/撤销后的状态提示。
2. 每天多个时间、每周指定日、15 分钟追提醒、23:00—07:00 静音。
3. 熄屏待机、清理最近任务、通知单独划除、勿扰模式及省电模式。
4. 打卡完成/确认未完成后取消通知，计数目标达标后取消后续提醒。
5. 重启后首次解锁恢复、时间和时区变化；强行停止后重新打开恢复。
6. 桌面两类小组件的添加、分组/习惯配置、缩放、多实例及快捷打卡同步。
7. 大字体、100 个习惯、长列表和长名称；无障碍读屏与可点击区域。
8. 保留签名的覆盖升级、备份恢复后数据保留及小组件重新选择。

Android 8、13、14、17 的实机/模拟器完整矩阵尚未执行。Android 14 及以上通知可被单独划掉，应用按下一次调度重新提醒；关闭权限或强行停止后不承诺提醒到达。
